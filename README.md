# Chrome Extensions

## Page Navigator

[Download Page Navigator v1.0.0](https://github.com/BluehatTom/Extensions/raw/refs/heads/main/Page-Navigator-v1.0.0.zip)

A Chrome extension with Top, Middle, and End buttons; live search as you type; heading navigation; previous-position history; and saved reading spots.

### Install

1. Download and extract the ZIP.
2. Open `chrome://extensions` and enable **Developer mode**.
3. Choose **Load unpacked** and select the extracted `page-navigator` folder containing `manifest.json`.
4. Pin the extension and refresh your open webpages.

The ZIP includes complete source, installation instructions, and validation notes. Navigation and search processing happens locally; no API key is required.

Version 1.0.0 passed 47 deterministic navigation and search logic tests. Real Chrome installation and visual rendering were not tested in the build environment.
